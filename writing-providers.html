Writing Providers ​

A provider package implements IDriver and exports only that type. DatasourceFactory.register stores it by name. The driver builds the connection, command, and transaction, and supplies row cell converters when native values are not already canonical cells.

Every provider names the type *Driver (JsonDriver, SqliteDriver).

Remarks ​

connection receives the options bag. A provider parses `DATASOURCE_URL` with [DatasourceUrlParser](./sections/datasource-url.md). command delegates to the connection's createCommand. transaction builds the dialect transaction. Isolation defaults to read committed.rowTypeConverters maps a canonical type name to a TypeConverter. SQL dialects register bool, datetime, uuid, decimal, and binary when the engine cannot return those as canonical cells. Memory, document, and file providers return an empty map.information is optional metadata a driver may publish. Each list is free-form text: descriptions for capability notes, overrides for dialect-specific behavior, and changeLogs for provider history. The default is unset.

Published drivers list that metadata (and rowTypeConverters keys) per language on Languages and Datasource Providers. Edit docs/DriverSummary.yaml, keep each driver's information in sync, then run npm run docs:drivers.

The statement factory formats SelectInsertedIdStatement as a SelectStatement, and the repository reads that row. Commands do not sniff SQL for the inserted id. SelectInsertedIdStatementTextRenderer.render throws until a provider overrides it.

columnType maps a canonical column type to the engine SQL type name. It does not convert cell values. The default returns the name unchanged. MySQL, Postgres, and SQLite override it and throw on an unknown name.typeConverter is an IMapping from a spec type name (`integer`, `string`) to a native column type. SQL drivers set a DeterministicTypeConverter. A sized field uses the type definition (`size`), not a generator flag. Concurrency is a where on the update or delete. defaultValueConverter maps a spec default token (UtcNow, NewId) to a native SQL expression. Other drivers leave them unset.

Assign the exported columnType function.

Inherit the default method.

Inherit the default method.

SQLite, MySQL, and Postgres each keep create-table rendering on their own CreateTableStatementTextRenderer. The statement factory does not subclass that renderer. It maps a compiled create table to the rendered text and maps SelectInsertedIdStatement to SELECT last_insert_rowid(), SELECT LAST_INSERT_ID(), or SELECT lastval(). Statement executeStatement and the reader overloads call the factory before the string execute. The renderer overrides column type. MySQL and Postgres also override default and identity. A Postgres bool default goes through the bool type converter, so 1 becomes TRUE. SQLite leaves identity empty. Every other statement is left unchanged. The factory is not exported.

The package exports only the driver type.

src/index.ts is one line, export { SqliteDriver } from "./SqliteDriver.ts". package.json exports points at dist/index.js.

That class is public. Connection, command, transaction, options, and converters are internal. InternalsVisibleTo opens them to the test project. GetExportedTypes() is exactly the driver.

lib.rs declares private modules and one pub use of the driver. pub items inside those modules stay crate-private.

PublicSurfaceTests in each C# provider test project, the exports only the provider test in typescript/datasources, and providers_export_only_their_provider in datasources reject a second export.
