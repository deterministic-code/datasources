# TypeConverters

`TypeConverter` is a thin named wrapper. Row dictionary conversion lives on `RowConverter`.

## TypeConverter

| C# | Rust | TypeScript |
| --- | --- | --- |
| `TypeConverter<T>` | `TypeConverter` | `TypeConverter<T>` |
| `Convert` | `convert` | `convert` |
| `ReverseConvert` | `reverse_convert` | `reverseConvert` |

## RowConverter

| C# | Rust | TypeScript |
| --- | --- | --- |
| `RowConverter` | `RowConverter` | `RowConverter` |
| `Convert` | `convert` | `convert` |
| `ReverseConvert` | `reverse_convert` | `reverseConvert` |
