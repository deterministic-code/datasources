# Skill

A progressive Cursor and Claude Code skill generated from these docs. The agent reads `SKILL.md`, then one topic file for the task.

## Download

[Download the skill](/datasources-skill.zip)

## Install

Unzip so the folder name stays `datasources` and `SKILL.md` is inside it.

### Cursor

```sh
unzip datasources-skill.zip -d .cursor/skills
```

### Claude Code

```sh
unzip datasources-skill.zip -d .claude/skills
```

Or copy `skills/datasources` into `.cursor/skills/datasources` or `.claude/skills/datasources`.
