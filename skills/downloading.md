# Downloading

## Installation

#### TypeScript

```typescript
npm install @datasources/core
```

#### C#

```csharp
dotnet add package Datasources
```

#### Rust

```rust
cargo add datasources
```

## Provider packages

Install providers with `npx @datasources/cli add <name>`. Do not invent package names.
