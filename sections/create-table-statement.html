ReferentialAction ​

rust
pub enum ReferentialAction

Properties

NameDescription
CascadeON DELETE / ON UPDATE CASCADE.
SetNullON DELETE / ON UPDATE SET NULL.

RestrictON DELETE / ON UPDATE RESTRICT.

Remarks ​

A compiled statement stores the table, columns, and constraints. StatementTextRenderer.render renders CREATE TABLE table (name TYPE [CONSTRAINT n DEFAULT v] [CONSTRAINT n NOT NULL], …, CONSTRAINT name …). Table and column names are interpolated as given. Default and check values are raw SQL fragments. Wrapped text has no table. Indexes use CreateIndexStatement. StatementTextRenderer.render uses CreateTableStatementTextRenderer. A provider subclasses that renderer and can replace render or override type, default, and identity. SQLite, MySQL, and Postgres override type so canonical names become engine types. MySQL and Postgres also override default and identity. A Postgres bool default goes through the bool type converter, so 1 becomes TRUE. Identity renders AUTO_INCREMENT or GENERATED BY DEFAULT AS IDENTITY. SQLite leaves identity empty. StatementTextRenderer.render leaves those changes off. Other commands use the rendered text.

Compile a CREATE TABLE ​

var createTable = new CreateTableStatement("users", [new Column("id", "INTEGER"), new Column("name", "TEXT")]);

Compile named constraints ​

csharp
var namedTable = new CreateTableStatement(
    "orders",
    [
        new Column("id", "INTEGER", new ColumnDefault("0", "df_id"), new NotNull("nn_id")),
        new Column("tenant_id", "INTEGER"),
        new Column("user_id", "INTEGER"),
        new Column("qty", "INTEGER")
    ],
    [
        new PrimaryKey("pk_orders", ["id", "tenant_id"]),
        new ForeignKey("fk_orders_user", ["user_id"], "users", ["id"], ReferentialAction.Cascade),
        new UniqueConstraint("uq_orders_user", ["user_id"]),
        new CheckConstraint("chk_orders_qty", "qty > 0")
    ]);
rust
let named_table = CreateTableStatement::new(
    "orders",
    &[
        Column::new("id", "INTEGER")
            .default(ColumnDefault::new("0", Some("df_id")))
            .not_null(NotNull::new(Some("nn_id"))),
        Column::new("tenant_id", "INTEGER"),
        Column::new("user_id", "INTEGER"),
        Column::new("qty", "INTEGER"),
    ],
    &[
        PrimaryKey::new("pk_orders", &["id", "tenant_id"]),
        ForeignKey::new(
            "fk_orders_user",
            &["user_id"],
            "users",
            &["id"],
            Some(ReferentialAction::Cascade),
            None,
        ),
        UniqueConstraint::new("uq_orders_user", &["user_id"]),
        CheckConstraint::new("chk_orders_qty", "qty > 0"),
    ],
);
typescript
const namedTable = new CreateTableStatement(
