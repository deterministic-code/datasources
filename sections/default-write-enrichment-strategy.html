DefaultWriteEnrichmentStrategy ​

Default nested write. Create uses DefaultCreateEnrichmentStrategy. Update uses DefaultUpdateEnrichmentStrategy. Delete uses CascadeDeleteEnrichmentStrategy. Each can be replaced.

Remarks ​

Set it on the repository write option. Create, update, and delete each delegate to the strategies passed here. A null or empty list clears a link when this strategy is eager. LazyWriteEnrichmentStrategy skips that null list. Nested writes join the transaction when they use the same connection.

Examples ​

Roll back a bulk update ​

csharp
var connection = await Setup();
var parentsRepo = new BulkCRUDRepository<Parent>(connection, new CRUDRepositoryOptions<Parent>
{
    Write = new DefaultWriteEnrichmentStrategy<Parent>(useTransaction: true),
});
var first = await parentsRepo.Create(new Parent { label = "a" });
rust
let connection = setup(&mut []).await;
let mut options = CRUDRepositoryOptions::default();
options.entity = "Parent".into();
options.write = Some(Arc::new(DefaultWriteEnrichmentStrategy::new(
    None, None, None, true,
)));
let parents = BulkCRUDRepository::new(connection, options).unwrap();
let created = parents
    .create_bulk(&mut [
        record(&[("label", Value::from("a"))]),
        record(&[("label", Value::from("b"))]),
    ])
    .await
    .unwrap();
let stored = parents.read(None, None, None).await.unwrap();
let mut created_ids: Vec<_> = created.iter().map(|row| num(row, "id")).collect();
let mut stored_ids: Vec<_> = stored.iter().map(|row| num(row, "id")).collect();
created_ids.sort();
stored_ids.sort();
